# Yomimi

Yomimi shows you what parts of a book were adapted into what parts of the show. Basically, it's an
episode to chapter or episode to page converter. It's meant to assist in reading the book and
watching the show at the same time. The idea is you read a bit, then watch the corresponding
episode, then read a bit more, and so on.

## Contributing

All contributions are welcome!

If you want to contribute data, data for books categorised by chapter are in `src/_data/seriesChapter` and the ones by page are in `src/_data/seriesPage`.
